# ADR 0009: Project license

Status: accepted

Date: 2026-07-31

## Context

Imaguncula is intended for open-source use, library reuse, packaged desktop distribution, and external contributions.

## Decision

License the project under either MIT or Apache-2.0 at the recipient's option. Apply the same terms to contributions unless a contributor explicitly states otherwise.

## Consequences

Consumers can choose a concise permissive license or Apache's explicit patent grant. Package metadata uses the SPDX expression `MIT OR Apache-2.0`.
